# 尺寸、线宽、余量与颜色

## 坐标与依据

建议内部用面板左上原点、X 向右、Y 向下、毫米为最终单位。明确 PDF 底向上与图片顶向下转换；分版同原点同画布。工程边界优先，照片只有参考配准精度。区分面板/外壳、含耳宽度和深度；缺失高度不靠照片比例冒充已确认尺寸。

轴向面框 `[x0,y0,x1,y1]`，实物 `W,H`：

```
sx = W / (x1 - x0); sy = H / (y1 - y0)
x_mm = (x - x0) * sx; y_mm = (y - y0) * sy
```

透视照片先校正到面板平面，不对仍有透视的原图直接套两个常量。仅标注原稿时可保留其展示比例，注明数值按宽高分别标定、页面非 1:1；未经授权不拉伸原稿外观。

## 法向线宽

原始描边宽 `w`，单位切向 `(tx,ty)`，换算后的法向宽：

```
t_mm = w * sx * sy / sqrt((sx * tx)^2 + (sy * ty)^2)
```

水平段 `w*sy`，竖直段 `w*sx`。非等比缩放中相同描边档因方向不同可能产生不同毫米宽度，不能横向比例乘所有线条。

填充斜带先映射至毫米，再用长边法线与两侧交点测距。阶梯带、尖头、过渡、曲线标局部截面或有依据范围，不把某一宽度宣称全图极值。色块可用宽×高；符号外接框不叫线宽。

同色填充与描边叠合，测最终可见联合宽度并检查叠画顺序；仅测单个对象则明确口径。遇到孔洞/间隙，不把离散区段合成一条粗带。

描边边界包含端帽、连接和斜接限制。曲线包围盒用曲线极值，不只是控制点包围盒。高分辨率渲染可验证几何方法，但写明采样精度，不把采样描述成解析精确结果。

## 四边余量

墨迹外缘包围盒 `[xmin,ymin,xmax,ymax]`：

```
left=(xmin-x0)*sx; right=(x1-xmax)*sx
top=(ymin-y0)*sy; bottom=(y1-ymax)*sy
```

分别计算全墨迹和所需分色。符号是否计入取决于声明范围，不默默略去。说明这是到名义矩形的最小正交余量，不是每段等距，也不是圆角/孔洞避让距离。负值如实报告为越界，不截为零。

灰面框与墨迹包络区分开；屏幕、通风区或安装耳产生大留白时说明从整块面板起算。照片框有误差时标“约/参考”，两位小数只是呈现精度。

## 测量工具

`scripts/measure_geometry.py --input job.json --output measurements.json` 使用标准库，仅支持已配准平面的独立 X/Y 缩放。曲线须先在指定误差下离散或另用原生曲线几何。以下任意测试尺寸不是默认值：

```json
{
  "frame": {"raw": [0, 0, 1000, 500], "mm": [200, 100], "basis": "user-confirmed panel"},
  "ink_bounds": {
    "black": {"raw": [10, 20, 990, 480], "includes_strokes_caps_joins": true}
  },
  "strokes": [{"id": "01", "anchor": [300, 200], "tangent": [1, 0], "width": 2}],
  "filled_sections": [{"id": "02", "anchor": [50, 5], "tangent": [1, 0],
    "loops": [[[0, 0], [100, 0], [100, 10], [0, 10]]]}]
}
```

墨迹框必须已含描边端帽连接；工具拒绝未声明此前提的数据，不从中心线框推导墨迹边界。多边形截面按偶奇规则，取包含锚点的连续填色区间；多对象同色联合须事先计算或另行核对。

## 颜色依据

记录颜色/分版名、来源、原稿颜色空间和值、显示参考、油墨确认状态、对应元素。不把所有深色默认为纯黑。

- 保留用户标准、PDF 专色和原稿 RGB/CMYK 各自来源。RGB/HEX 精确对应；RGB/CMYK 依赖 ICC 和渲染条件，不是无条件等价。
- 照片取色只能估计；反光、白平衡和显示器不提供油墨认证。没有品牌依据不编造 Pantone。
- 两组蓝色不同，说明差异。只要求颜色说明则保留原值；明确授权统一才重着色，并复验各版。
- K100 可写 `CMYK 0/0/0/100`；品牌色名仅在有依据时使用，单个项目的色值不是通用默认。
- 蓝色晒版黑稿显示 100% 黑色是正常的，不能因此把油墨改黑。
- 原有红黄图形是设计；红尺寸、灰框、表格和照片是核对辅助，排除出生产版。

首页可列色块、色值、分版用途、预览差异、其他符号色、单位和页面比例。只写真实适用事项，不复制模板中的最低线宽、未确认尺寸和工艺声明。
