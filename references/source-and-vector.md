# 图片提取与原稿保留

## 输入清单

每款记录 `panel_id`、原图/原稿路径与哈希、尺寸来源与最新宽高、面框四角、是否含安装耳、保留/排除元素、颜色来源、输出版本。源文件只读，转换副本另存，不把用户原图复制到 skill 目录。

识别实际内容：PDF 可能是照片、路径、混排、透明度/裁剪/嵌套 XObject。检查页面旋转、单位、资源、累积变换和颜色空间，真实矢量优先复用。照片和对应矢量可能共享像素坐标，但必须以多个可见特征验证。原稿没有面框时，不得把 A4/A3 卡片边缘当产品外框。

## 照片到几何

1. 保留完整原图，另建裁切和透视校正副本；记录照片到面板平面、面板平面到毫米的转换。
2. 用真实四角/直边或工程图作基准。正面矩形可轴向裁切；斜拍采用单应变换，必要时先处理镜头畸变。圆角用直边交点定义名义矩形，不凭阴影找框。
3. 分区识别所需油墨。颜色阈值仅作候选掩膜；暗色机壳、孔边、反光、文字、拼缝不自动等于丝印。
4. 长直段共线、真实折点清楚、相接轮廓连续；曲线用少量控制点，不沿压缩噪点加密节点。无依据不强制对称；先判断重复条纹差异是设计还是失真。
5. 上下左右、转角、斜纹、细线和小曲线分别放大。被旋钮或反光遮挡部分标记不确定，不能假装恢复隐藏机械细节。
6. 需要兼容制版时用闭合填充轮廓，或在副本展开描边；保留孔洞和填充规则，不用白色遮罩伪造孔洞，不把面框导入墨迹。

不要用生成式位图工具重创精确几何。流畅意味着去掉数字噪声和断裂，不意味着把设计折角全部圆滑。

## 已有矢量

复制原页面/矢量对象，加独立标注层或裁剪放大。复用内容流时保留 graphics state、颜色资源、透明度、裁剪和累积矩阵，不能只取路径而遗失描边填充语义。仅要求标注时，不擅自删细线、警示图标、加减号、电源符号和文字轮廓。

需要转换以生成分色/透明预览时，保留不可变原稿和转换对照。两类独立证据：

- 结构：源哈希不变，关键路径、颜色、描边操作或语义几何保持。资源重命名/等价变换会改变字节哈希，需解释比较口径；只看对象总数不够。
- 显示：同坐标、同渲染设置比较前后，排除新增标注，检查轮廓、孔洞、颜色和裁剪差异。

解析器遇到不支持的操作应报告并换可信方法，不能跳过后宣称全部保留。
