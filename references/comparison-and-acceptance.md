# 原图对比与反复验收

不能以“已生成”或只看首页代替验收。

## 每款证据

1. **完整原图**：保留未经改动的照片/效果图以核对型号范围；裁切、校正图另存。
2. **同坐标并排**：照片面板和最终矢量预览同画布、比例、方向、原点，注明校正方法，另附完整原图缩略防止裁切隐藏问题。
3. **配准叠加**：高对比半透明墨迹显示双边、偏移、比例和角点问题；同时保留原色总稿，不能把叠加色当生产色。
4. **局部放大**：覆盖实际存在的细线、折角/曲线、小间隙、斜纹、端点、符号和不确定处，有针对性选区，不机械凑数量。
5. **矢量基准**：原稿模式再核对原始与最终保留矢量的结构/显示，照片拟合不能取代原稿保真。

默认把原图并排对比放进核对 PDF 或另交清楚命名的图；叠加/局部可另附。用户只要一个合册时加入对比页或在每款概览保留原图，不能让结论依赖用户看不到的内部文件。

## 配准工具

`scripts/make_comparison.py`（Pillow、NumPy）生成对照、叠加、局部和来源清单：

```text
python make_comparison.py --reference photo.png --artwork final-transparent.png --frame "120,80,1820,780" --output-dir proof-r01
python make_comparison.py --reference angled.png --artwork final-transparent.png --quad "120,90;1700,120;1680,900;140,920" --crop "corner:0,0,0.2,0.25" --output-dir proof-r02
python make_comparison.py --reference rectified.png --artwork final-transparent.png --aligned --output-dir proof-final
```

数字仅为示例。四角按照片左上、右上、右下、左下，是投影配准，不证明物理尺寸。`--frame` 为轴对齐照片矩形，`--aligned` 仅在两图已经同坐标时使用。

需要密集细节证据时可增加：

```text
python make_comparison.py --reference rectified.png --artwork final-transparent.png --aligned --panel-mm "180,120" --panel-mm-source "已确认图纸及版次" --tile-grid "4,3" --tile-overlap 0.1 --blink --checkpoint "landmark:360,240,360,240" --output-dir proof-r03
```

这个示例假定两幅输入同画布且有对应地标，尺寸和点位必须换成实际依据。参数均按需要使用：

- `--panel-mm W,H` 只在输入 artwork 完整画布对应面框时使用，同时必须提供非空 `--panel-mm-source` 写明依据，检查毫米宽高能否在每维 ±0.5 px 的取整范围解释同一像素密度；不检查 PDF/SVG 的真实毫米页尺寸、DPI 或边框身份。工具无法判断所填来源是否真实，仍由执行者核对。
- `--tile-grid 列,行` 生成 `tile_index.png` 和原生 artwork 分辨率的重叠三联块，参考区域直接从原图配准取样；默认重叠 0.1，最多 100 块，按细节辨识需求选择，不机械沿用示例网格。每块数据在 manifest 中，不证明已被人工查看。
- `--checkpoint name:refx,refy,artx,arty` 可重复，坐标分别是 EXIF 校正后的原参考图/原 artwork 像素（不是 `--width` 输出像素）。点不参与四角拟合；角点与重复参考点拒绝充当独立证据。残差不自动判通过，也不能证明该点确为同一物理特征。
- `--blink` 输出概览分辨率双帧 GIF。`--blink-background white` 白底可能隐藏白墨；`reference` 保留参考底图会隐藏成稿漏线。GIF 还有调色板减色，必须结合棋盘底原色图、差异图和分块检查，不能单独验色/验完整性。

每轮使用新的或空的输出目录。工具拒绝非空目录，避免旧分块、旧闪烁图与新 manifest 混版；需要调整证据参数时同样另开版本目录。

**独立核对纵横比。** 工具把参考图校正到 artwork 的画布比例；若 artwork 已被错误拉伸，参考图会一起拉伸，叠加仍可能吻合。因此生成证据前，单独检查生产 PDF 页或 SVG 的毫米宽高、viewBox 映射与已确认 W/H；需要 1:1 的栅格预览还应核对像素纵横比（容许由取整产生的像素差，不能自定宽松比例）。记录这项独立核对的来源。非 1:1 的原稿展示图可保留原比例，但要明确 X/Y 标定关系，不能用叠加图证明机械比例。

最终预览优先透明。仅当明确无白色油墨且输入为白纸背景，才用 `--white-background`；否则会误删白色设计。不用去色阈值掩盖漏线。证据与最终几何/导出版本匹配，输入哈希写入记录。

阴影、压缩、反光使全图像素差/相似度没有通用意义。定量边缘误差只用于明确配准且有目标区和容差的情形，结合人工审查，不设跨项目“95% 相似即通过”。

复杂图样的采样、分块与交互查看见 [视图与覆盖检查](visual-inspection.md)。同坐标分色之间的差异图与拓扑诊断见 [掩膜差异诊断](mask-comparison.md)。先检查原始差异，再看有依据的容差结果；照片置信度与生产容差不能混用。忽略区/排除元素应可见且列出原因，不能通过扩大排除区使结果看似通过。

## 验收闭环

### 第一轮：全貌与范围

逐款检查原图/尺寸/型号对应、方向比例、漏线多线、文字/壳缝误收、符号误删、颜色分区、面框与包络、所有分色的画布原点。区分制作错误、允许的有意改动、材料造成的未决项，不为像素相似度描反光与噪点。

### 第二轮：放大细节与量值

与原图对照直线、交接、弧线连续性、控制点抖动、端帽、尖头、斜纹、孔洞、闭合、自交和细缝。核对截面落点、同色叠合、变宽和方向变化。检查单位、尺寸依据、法向宽、外缘余量和分色范围；检查数字引线遮挡、指向和编号表对应。

原矢量验证路径/颜色保留，不能只查对象数量。首轮没问题，也要换倍率和检查口径复验；可用独立代理。无需为凑轮次重复同一测试。

复杂图样同时维护“产品 → 颜色/层 → 区域 → 版本 → 证据 → 实际查看状态”的覆盖表；独立复查者拿原始资料和当前成稿按相同范围检查，先给发现，不只确认前一人的结论。逐色检查应发现错分色、漏岛、孔被填实、细桥断开等总图可能隐藏的问题。

### 修正后的复验

每项记录 `id / 产品 / 版本 / 证据 / 发现 / 处理 / 复验结果`。修正后重新导出受影响总稿、分色、标注和局部图，由新文件重渲染，不用旧截图。复查修复点及相关区域是否产生断线、变形或套位偏移。

问题位置写面板归一化坐标或已校准毫米坐标，附颜色/层、局部图及预期/实际。区别错误类型：配准、几何、拓扑、颜色/分版、标注、导出，先修根因。记录修前/修后文件哈希；源或渲染设置变更使相关旧证据失效。复查修复点、邻近相交/同色联合，以及更新后的全貌，防止局部修改带来其他区域退化。

若连续返修仍不能改善，先查错误基准、源分辨率或不支持的图形语义；不要继续加节点、模糊或加粗掩盖。不存在为了凑轮次而必须改动的要求，也不以固定轮次代替通过标准。

### 最终交付检查

全部修改/合并后检查实际交付文件：

- 逐款、逐色、逐页打开，文字正常，无裁切遮挡。
- 生产版无照片、标注色、参考框、编号；核对页不冒充干净晒版。
- 实物尺寸、原点、页面单位和比例正确；只有尺寸已校准生产稿可称 1:1。
- 分色叠合还原总稿，版间无平移/缩放，原有元素按范围保留。
- 目录、页码、颜色说明与正文一致，最新数据未被旧封面或旧导出覆盖。
- 照片模式有配准/细节证据；原稿模式有保真证据。

记录所验文件哈希或版本。结论分为“数字文件核对通过”“参考版，存在明确未决项”“未通过”，不把视觉核对写成实物打样/工厂验收。

## 停止条件

可观察错误已修复，最终输出通过，材料限制已明确时交付。缺少高度、隐藏轮廓、未知标准色或机械基准需指出具体缺口，继续独立可做部分，不无限重描或编造。真实未决项存在时不能标生产确认。

记录示例：

```text
产品 P02 / r03 / proof-final/detail-corner.png
发现：右下折线错接到外壳拼缝。
修改：按校正原图恢复端点，保留设计尖角。
复验：r04 新总稿、蓝版与叠加图核对，端点正确且套位一致。
剩余：照片边缘反光，面框定位仍为参考，不声明机械精度。
最终文件：记录路径、版本或哈希。
```
