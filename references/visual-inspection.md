# 视图能力与完整覆盖

视图是判断依据。生成图、计算指标和真正打开图检查是不同动作；记录实际打开的文件及所见。图像工具优先，浏览器查看器可辅助交互；工具不可用时说明哪些视觉检查未完成，不能用 OCR 代替曲线、间隙、遮挡判断。

## 选择视图

| 判断内容 | 有效视图 | 避免的误判 |
|---|---|---|
| 型号、元素范围、构图、方向 | 完整原图 + 成稿总览 | 裁切漏掉边缘；把外壳/文字当装饰 |
| 透视和几何错位 | 同坐标并排、叠加、独立地标 | 用参与拟合的四角残差证明配准正确 |
| 细线、端点、弧线、微小间隙 | 原始分辨率重叠分块 + 原生矢量局部重渲染 | 把整图缩略再放大当高分辨率证据 |
| 白色、浅色、透明或孔洞 | 浅底、深底、棋盘底及 alpha/单色轮廓 | 白色墨迹与透明都显示成白底 |
| 突然位移、删增图形 | 同步缩放/拖动、擦除、闪烁视图 | 不同视图独立适配尺寸导致错位或错误吻合 |
| 分色混淆、套位、遮盖 | 每版隔离 + 按原绘制/叠印语义复合 | 所有颜色转同一洋红后看不到错分色 |
| 孔洞、连通、细桥、孤岛 | 二值掩膜差异 + 原色局部 | 面积几乎相同就忽略结构变化 |
| 标注可读性 | 实际核对 PDF 的整页与局部渲染 | 只看未加标注的 SVG |

## 先确定资料能支持什么

记录原图原生像素、面板在图中的有效像素与最终预览尺寸。要辨认的最小线/缝如果只有约一两个像素，不能从抗锯齿灰边得出可靠毫米值；增加源矢量渲染分辨率或使用真实更清晰资料。放大位图不增加信息，AI 超分不作几何或颜色真值。

工程宽高、生产画布毫米尺寸、像素纵横比独立核对。单应变换只拟合一个平面；镜头弯曲、曲面和跨平面元素见复杂处理参考。优先用没参与拟合、分布在内部和边缘的可识别地标复核，记录参考与成稿坐标、残差和解释；没有可靠地标就保留不确定性，不伪造零残差。

## 分块与阅读顺序

先全貌再局部。密集图样按面板坐标建立重叠网格，行列与图中位置对应，检查所有有设计内容的格；留白区检查意外墨点/溢出。重叠用于发现恰落在切块边的断线，并非增加独立证据。特征跨度超出一块时额外生成跨块视图。

块大小取决于源分辨率、最小特征及图像工具的实际显示尺寸，没有通用 2×2 或固定倍率。若工具缩小图片，将块再细分或读更小区域。每块在覆盖表标 `未看 / 已看无发现 / 有问题 / 资料不足 / 有意排除`，不能把“已生成全部块”写成“已检查全部块”。先看边界、细缝、节点密集、分色交界与遮挡，再完成其余区域；风险顺序不能取代覆盖。

对矢量尽量按局部包围框重新渲染，记原点与比例。对照片直接从原图逆映射取该区域，避免连串缩放。`make_comparison.py` 的分块基于输入 artwork 的原生像素；若透明预览本身太小，先重渲染再运行。

## 离线交互查看器

```text
python build_review_viewer.py --manifest proof-r02/manifest.json --output review-r02.html
```

读取 `make_comparison.py` 的证据清单，检查图像哈希后嵌入离线 HTML。支持同坐标叠加、擦除、闪烁、同步缩放拖动、浅/深/棋盘底，以及记录坐标和导出人工观察。查看器显示的是配准证据栅格，`1 px` 是栅格像素显示比例，不是实物 1:1；生产矢量、专色、尺寸仍需独立核验。

通过环境可用的浏览器打开；可导出图像/沿用 PNG 供不支持 HTML 的用户。不要上传私有面板图片到外部站点。浏览器当前显示成功也不能证明导出 PDF/制版文件正确。

观察记录绑定 manifest 哈希和源版本，默认未核验。导出记录只是人的发现，不生成自动通过。发现位移后固定原配准核对修正，不通过移动参考图来消灭真实成稿差异。
