# 复杂丝印的重建与复查

按实际复杂点选用下列方法，不给简单线条增加无关流程。先判定复杂性来自照片、几何、文件结构还是印刷工艺；将问题定位到具体区域、颜色或对象，避免一处不清楚就重画整款。

## 多来源与非平面外观

每款指定主依据，辅助照片只补充其可辨细节。记录型号、版次、拍摄方向、可见范围和用于判断的区域；同系列不同面板、改版前后或左右镜像款不能拼成一个图。来源冲突时，优先采用用户明确指定的版本与可靠原稿/工程资料，并保留冲突记录。辅助照片各自配准，不把未校正的像素坐标直接拼接。

平面斜拍可用单应变换；先用框边和分布在面内的独立特征检查配准。不能只用被重画的线条反向拟合变换，再以同一线条吻合证明重建正确。镜头畸变、翘曲、折弯面与圆柱面会产生不同误差：

- 平面不同区域仍系统性弯曲时，检查镜头畸变及是否实际为曲面，不靠局部拖拽让每条线都对齐。
- 折弯面按各自平面核对，并区分投影视图、展开图与折弯后实物。没有展开尺寸、弯曲半径或可信展开原稿时，不从照片生成已确认的展开生产尺寸。
- 曲面/透视遮挡不能由四角变换恢复真实长度。可交付可见区参考重建与明确待定区；不能把未见部分自动补成对称线、圆弧或连续纹样。

## 分区建模与几何细节

为复杂图分配稳定区域 ID，列出边界、色版、几何类型、依据、相邻关系和未决点。先校整体位置、重复规律和关键端点，再细化局部；拼接时复查公共边和交接点，避免各区单看正确而整体错位。

- **变宽曲线**：保留原生曲线或以两侧轮廓重建填充带。先确定极值、拐点、尖头和接点，再用少量 Bézier 控制点拟合；不要用均匀粗描边代替真实变宽带。曲率突变可能是设计，不强制所有接点切向连续。
- **曲线测量**：在最终毫米坐标中指定截面位置和法向，检查与两侧轮廓的对应交点；凹曲线可能有多次相交，不跨孔洞或邻近回折带取总跨度。曲线离散须记录误差依据，并核对缩小步长后结果是否稳定；现有直段测量脚本不提供原生 Bézier 的解析宽度或全局极值。
- **尖角与细缝**：检查端帽、斜接、尖头方向和最窄处。展开描边、路径简化或布尔运算后复查尖刺、断裂、窄缝闭合与圆角改变；“更流畅”不授权抹掉设计折点或收尖。
- **重复条纹**：逐区核对数量、节距、起止相位、倾角、裁切边界和端部变化。可以复用有证据的母单元，但最后一条、转角处或左右两侧可能有真实差异；不得默认等距、镜像或补齐被遮挡的周期。
- **拓扑**：核对有意连通的部分仍相接、独立岛仍分开、孔洞仍透空、分支和交叉关系正确。关注窄桥、文字内孔及装饰负形；组件数与孔洞数只能辅助，不能代替逐区核对。抗锯齿产生的微小连通不是设计依据。

## 原矢量与复杂成像语义

原矢量优先于照片重描。保留源副本；解析能力不足时使用可信渲染/矢量工具检查，不跳过未知操作后输出“完整保留”。变换、裁剪、填充与透明度共同决定可见墨迹，不能仅提取路径坐标。

- **复合路径与裁剪**：区分 `evenodd` 和 `nonzero`，核对内外环方向、嵌套裁剪、蒙版及变换后的裁剪边缘。孔洞不是白色遮罩；布尔联合前确认同色对象和当前可见状态，避免填掉负形或放出原本裁掉的图形。
- **叠印与挖空**：保留叠印/挖空设置，按实际分版查看交叠区；普通 RGB 预览看似一样，也可能对应不同版面。不能只按屏幕最终颜色反推出油墨版。
- **透明与混合**：检查对象/组透明度、软蒙版、混合模式及隔离组。透明展平可能产生拼缝、颜色变化或位图区域，必须复验转换结果；不把无法分解的透明效果无说明地变成单色实心块。
- **专色与混合色**：保留原色版名称、专色调值及 `Separation`/`DeviceN` 等颜色语义。多个色版叠合得到的预览色不是新专色；一个专色的不同网目调值也不是多种油墨。颜色空间、ICC 转换与替代显示值分别记录，不从近似 RGB 值猜测制版含义。

## 文字、图标与位图范围

完整原稿标注时保留文字、图标、极性符号及警示颜色；装饰线提取时按用户已定义范围执行，不能把其范围推广到其他款。

文字优先保留嵌入字体或已有轮廓，核对字符、字距、基线、方向、负形和特殊符号。缺字体时先查原稿可用字体资源或索取原始轮廓，不静默换相近字体；OCR 只能辅助识字，不能作为精确字形。转曲应在交付副本进行，并复验小字号、内孔和间距。仅有低清照片时，字样的识读结果和几何重建置信程度分别记录。图标不能凭通用图标库替换相似符号。

含位图、网点或渐变时，先辨认它是设计本身、源文件栅格化，还是照片中的印刷/拍摄纹理。不要逐个描摹照片网点制造伪精确矢量，也不要自动把渐变改成实色。可靠位图可保留为独立印刷元素，并按最终实物尺寸核对有效分辨率；网目、角度、调值范围、加网方式和最低可印点须来自实际工艺或供应商要求。材料不足时保留参考外观并标出待确认范围，不声称已完成可生产网版。

## 分色套位与有依据的工艺调整

所有版共用最终毫米画布、原点、方向和比例。检查单版、逐对叠版及全部叠合，核对细缝、窄桥、跨色交接和交叠区；重组后的外观与总稿一致还不足以证明专色/挖空语义正确，须同时检查实际各版内容。

陷印、扩边/缩边、线宽补偿、套位标记、网点及版外留白均依用户或供应商依据设置；不得默认加入固定毫米数。标记不能落进产品印刷区域，未明确需要时不添加生产标记。声明公差的来源和作用对象，区分几何测量误差、照片定位不确定性与印刷套位公差。工艺调整产生的有意差异另存/标注，不把它隐藏成“与原稿一致”。

## 对比覆盖与判断证据

先用全貌确认方向、比例、范围和相位，再逐区查看实际输出尺度与足以辨认最小目标特征的放大视图。放大低清图只方便观察，不能增加细节证据；预览降采样可能吞掉细线，疑点需回到最终文件局部重新高分辨率渲染。复杂区域逐一记录覆盖状态，不只选最好看的几个局部；无关的空白区域无需机械细分。

| 症状 | 方法 | 复验时保留的证据 |
|---|---|---|
| 一侧吻合，另一侧持续偏移 | 独立核对尺寸、镜头畸变、平面假设与配准基准 | 全貌、分布式基准点及各区残差；不只看拟合用点 |
| 曲线发抖或变宽带变成等宽 | 对照两侧轮廓，减少噪声节点，保留设计极值/拐点 | 原图与最终导出局部叠加、指定截面位置 |
| 条纹局部似乎一致，整体错节 | 清点数量、节距和起止相位，检查真实不对称 | 覆盖整段的对比及两端放大 |
| 小孔被填、窄桥断开、独立岛粘连 | 检查填充规则、描边展开、布尔操作和采样分辨率 | 原/新负形与连接关系，实际尺度及高分辨率局部 |
| 总稿正常，单版缺元素或多色误合 | 核对裁剪、专色、叠印、透明度和各版语义 | 逐版预览、叠版还原及关键交叠区 |
| 符号/小字“差不多”但形状不同 | 查原字体/轮廓和字符范围，不以 OCR 或替代字体定稿 | 字形、内孔、基线及字距的同坐标对照 |
| 反光、遮挡或低清造成轮廓多解 | 用同款辅助依据补证，限定不确定区域 | 来源关联、可确认边界及明确未决点 |

发现问题后更新源几何、相关分版与标注，重导出并从新文件生成证据，复查修复区及相邻依赖区域。记录“已纠正的制作错误”“有依据的有意差异”“仍不可确认的局部”三种状态，不能把未决区域从对比中裁掉。完成可做部分后交付真实结论；数字检查不替代实物试印，不因复杂而引入逐步审批或无止境重画。
