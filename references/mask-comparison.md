# 独立分色掩膜差异诊断

`scripts/compare_masks.py` 使用 Pillow、NumPy，无 SciPy 依赖。用于已明确对齐的两个**单色墨迹掩膜**，帮助定位缺失、多出、断开和孔洞变化。它不自动配准、不修图、不输出“生产通过”，也不把相似率当验收结论。

## 什么时候使用

- 原矢量模式：将原稿与最终文件按相同画布、同一分色、同分辨率、同一渲染器导出透明 PNG，检查是否改变原有墨迹。
- 照片重建模式：先核实原框和投影配准，再以明确语义选择出参考色层；另审查参考掩膜是否误收阴影、文字、孔洞或壳缝。不能对整张照片做亮度阈值后称为真实丝印。
- 复杂多色：蓝、黑、白及其他实际油墨各跑一次；半透明抗锯齿边缘保留一致渲染条件。颜色混在一张图的 alpha 中会失去分色身份，不能检验错色或套位。

两个掩膜必须已经具有相同像素宽高、原点、方向、面框和比例；同尺寸只是必要条件。先独立核对机械画布和完整墨迹范围，不能靠共同拉伸两图证明比例正确。工具不会重采样、裁切或猜测坐标。

## 命令

透明 PNG 以 alpha 判墨，不看 RGB，因此白墨不会被删掉：

```text
python scripts/compare_masks.py --reference original-blue.png --candidate final-blue.png --mode alpha --ink-name blue --aligned --tolerance-px 0 --output-dir proof-blue-r01
```

人工确认的单色掩膜使用 `L` 或 `1` 模式 PNG，白色为墨、黑色为空白：

```text
python scripts/compare_masks.py --reference reference-white-mask.png --candidate candidate-white-mask.png --mode grayscale --ink-name white --aligned --threshold 128 --tolerance-px 1 --output-dir proof-white-r02
```

`--threshold` 为包含边界的 `>=` 阈值，范围 1–255，默认 128。两份输入用相同阈值；完全不透明的 alpha 被拒绝，以免把白纸背景当整版墨迹。确有整版油墨时明确提供灰度掩膜。输入仅支持 PNG；有非默认 EXIF 方向需先显式归一化。

已确认完整画布就是面框时，才附加毫米换算：

```text
python scripts/compare_masks.py --reference original-black.png --candidate final-black.png --mode alpha --ink-name black --aligned --tolerance-px 1 --panel-mm "180,120" --confirm-panel-frame --scale-evidence "用户确认图纸 A 的面框宽高，画布边缘与该面框一致" --output-dir proof-black-mm
```

数字为示例，不是通用面板尺寸。工具要求宽高可由共同像素密度解释，每个画布方向最多有 0.5 像素取整差。错误纵横比直接拒绝；人工声明、图纸来源和换算比例写入报告。像素面积换算不是矢量面积、实物测量或公差证明。

有意改动需有明确依据，不能悄悄排除。可重复指定像素矩形（左上含、右下不含），或提供同画布灰度排除掩膜；亮像素为不检查区域：

```text
python scripts/compare_masks.py --reference original-blue.png --candidate final-blue.png --mode alpha --ink-name blue --aligned --tolerance-px 0 --ignore-roi "20,30,60,50" --ignore-mask approved-change-mask.png --ignore-reason "用户批准编号区更换，审批图 B；这些区域另按新设计复查" --output-dir proof-blue-approved-changes
```

排除项取并集，报告逐项范围、合计覆盖、被排除的墨迹及差异像素数量；在总图上用黄色显式标出，不能称为已验区域。排除区域不会作为容差匹配的参考墨迹。全画布被排除会拒绝执行。拓扑计数仍基于**完整输入**，包含排除区，避免裁断人为制造岛和孔；必须结合排除记录解读。

## 输出怎么读

- `difference-raw.png`：共有墨迹深灰，参考有而候选缺失为洋红，候选多出为青色，不检查区黄色；所有原始差异均保留。
- `difference-tolerance.png`：容差范围内的缺失/多出变为浅粉/浅青，范围外保持饱和色。它没有删除原始差异。
- `regions.png`：原始差异连通区域的框和编号，供定位；编号和框可能盖住小细节，必须同时看无标记的原始差异图。
- `reference-mask.png`、`candidate-mask.png`、`ignored-mask.png`：阈值后的完整墨迹和排除范围，用于复现与人工核实。
- `report.json`：输入/输出哈希、参数、覆盖范围、分项像素数量、原始和容差外区域、毫米依据及完整输入的拓扑计数。始终是 `human_review_required`。

区域按像素数从大到小排列。`--max-regions` 只限制 JSON 明细和图上编号，**不抹掉总图上的小缺陷，也不改变全部区域和像素总数**；报告列出未进入明细的区域数和像素数。需要逐项清单时增大上限并分区复查。没有最小面积过滤，不用平均差异掩盖大量小缺陷。输出同名文件存在就拒绝，下一轮用新目录保留证据。

## 容差与复杂细节

`--tolerance-px` 必须显式给出，非负且有限。它使用像素中心间的欧氏距离：半径 1 包含上下左右一像素，**不包含对角一像素**；半径小于 1 只匹配同一像素。双方分别寻找附近对方墨迹，缺失和多出分别统计。此容差是诊断参数，不能直接当制造公差。半径越大计算越慢（纯 NumPy，约随半径和画布面积增长），先在合适分辨率和有依据的小半径诊断，不能为“过检”扩大半径。

临近线条可能被容差匹配到错误的邻线：一根细线完全漏掉，若旁边有另一根线，容差外计数仍可能为零。因此**容差图、原始差异图、拓扑变化和局部放大必须一起看**。文字、网格、密集斜纹、窄槽、独立小岛、白墨和异色交接不能只查总面积。最小关键特征要在渲染中有足够像素可辨，分辨率不足时增加分辨率再导出，不用缩略图判线宽；必要时以多个明确记录的阈值确认抗锯齿敏感性，不能从中挑一个最像的结果来掩盖缺陷。

拓扑约定：墨迹和差异区域为 **8 连通**，孔洞按 **4 连通空白**中不接触画布边缘的分量计数；对角接触会连接墨迹。报告连通分量、孔洞、最小岛/孔以及墨迹触边数，不做去噪、闭运算、补洞或删岛。连接数减少可能来自桥连，增加可能来自断线；孔数变化可提示堵孔、开口或错误连接，但要对照局部实际形状。计数相同也可能是此处漏孔、彼处新增孔，绝不能据此判拓扑一致。阈值、裁切和分辨率均影响计数，软件之外的物理连通性仍需矢量和工艺检查。

每次修正后从新版本重新导出并重跑，回看原始差异中对应缺陷消失且无新增异常，再复查实际生产矢量、分色套位和标注。工具结论不替代原图视觉检查或最终文件验收。
